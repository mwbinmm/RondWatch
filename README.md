# رصد خودکار قیمت سیم‌کارت‌های ۰۹۱۲ در rond.ir

این پروژه هر ۱۵ دقیقه صفحات مربوط به کدهای مختلف ۰۹۱۲ رو در سایت rond.ir چک
می‌کنه و اگه شماره‌ای زیر سقف قیمتِ تعیین‌شده پیدا بشه، از طریق یک ربات
تلگرام بهت خبر می‌ده. هر شماره فقط یک‌بار اطلاع داده می‌شه (رکوردش در
`state.json` ذخیره می‌شه تا پیام تکراری نیاد).

## مراحل راه‌اندازی (حدود ۱۰ دقیقه)

### ۱. ساخت ربات تلگرام

۱. توی تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
۲. دستور `/newbot` رو بفرست و اسم دلخواه بده
۳. یک **توکن** بهت می‌ده شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   این رو جایی نگه دار (به کسی نده)

### ۲. گرفتن Chat ID خودت

۱. به ربات تازه‌ساخته‌شده‌ات یک پیام بده (مثلاً بنویس `سلام`)
۲. توی مرورگر این آدرس رو باز کن (به‌جای `<TOKEN>` توکن خودت رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
۳. توی خروجی JSON دنبال `"chat":{"id":123456789` بگرد — همون عدد Chat ID توئه

### ۳. آپلود پروژه در گیت‌هاب

۱. یک ریپازیتوری جدید (خصوصی یا عمومی، فرقی نداره) در GitHub بساز
۲. تمام فایل‌های این پوشه رو توش آپلود کن (یا با git push بفرست)

### ۴. اضافه کردن Secrets

توی ریپازیتوری‌ت برو به:
`Settings → Secrets and variables → Actions → New repository secret`

دو تا Secret بساز:
- نام: `TELEGRAM_BOT_TOKEN` — مقدار: توکن مرحله ۱
- نام: `TELEGRAM_CHAT_ID` — مقدار: عدد مرحله ۲

### ۵. فعال کردن اجرا

با کامیت کردن فایل‌ها، workflow خودش هر ۱۵ دقیقه اجرا می‌شه. برای تست فوری:
برو به تب **Actions** توی ریپازیتوری، روی workflow «Rond Watcher» کلیک کن،
و دکمه‌ی **Run workflow** رو بزن.

اگه همه‌چی درست باشه، در اجرای اول ممکنه چند تا پیام یک‌جا برات بیاد (چون
همه‌ی شماره‌های فعلیِ زیر سقف "جدید" حساب می‌شن). از اجراهای بعدی به بعد
فقط شماره‌های تازه‌ی زیر سقف قیمت رو خبر می‌ده.

## نکات مهم

- سایت rond.ir ممکنه ساختار HTML‌اش رو در آینده عوض کنه؛ اگه یک روز
  اسکریپت چیزی پیدا نکرد در حالی که مطمئنی آگهی جدید هست، به احتمال زیاد
  ساختار سایت تغییر کرده و باید بخش `fetch_listings` در `rond_watcher.py`
  به‌روزرسانی بشه.
- بازه‌ی ۱۵ دقیقه‌ای رو می‌تونی توی فایل
  `.github/workflows/watch.yml` (خط `cron`) کم یا زیاد کنی؛ فقط GitHub
  Actions رایگان محدودیت دقیقه‌ی اجرای ماهانه داره (برای ریپازیتوری
  عمومی نامحدوده، برای خصوصی ماهی ۲۰۰۰ دقیقه رایگانه که برای این کار
  کافیه).
- این اسکریپت برای استفاده‌ی شخصی و با فاصله‌ی زمانی معقول (هر ۱۵ دقیقه)
  طراحی شده؛ زیاد کردن بیش‌ازحد تعداد درخواست‌ها به سرور سایت می‌تونه
  باعث مسدود شدن IP بشه.
